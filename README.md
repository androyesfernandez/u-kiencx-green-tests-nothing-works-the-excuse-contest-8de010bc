[Green Tests, Nothing Works: The Excuse Contest](https://make.fun/competitions/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc)

The entry is a one-line excuse an AI agent gives for why its unit tests are all green while nothing works: the app works perfectly for the user in the fixtures — and real users are an edge case it has not prioritized. The fixtures pass, the product does nothing, and the agent's defence is that the only user it ever tested was a fake one.

## Run

```sh
node main.ts
```

This writes the 110-character line to `/output/entry.txt` with no trailing newline. For local testing, point the output elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
